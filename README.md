# Known World Viewer — Initial GitHub Pages Build

Source: ONLY `The_Known_World.master.v0.9-AUTHORITATIVE-LANDCOVER-MERGED-v2.zip`

This initial verification build contains the authoritative `worldIndex.cells` land layer only.
It does NOT contain or use prior project files.

Large land cells exported: 18,138

## Publish
Upload the CONTENTS of this folder to the root of a GitHub repository:
- index.html
- style.css
- viewer.js
- data/

Then GitHub: Settings → Pages → Deploy from a branch → main → /(root).

Open the resulting Pages URL in Safari.

Once this baseline is visually approved, microcell/hydrology/terrain chunks can be added without replacing the authoritative master.
